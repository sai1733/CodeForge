# CodeForge Frontend Client

This directory contains the React.js application powered by Vite, utilizing Context API and useReducer for global state management.

## Stack
- React.js (Vite)
- Context API + useReducer (State management)
- Axios (API clients)
- Monaco Editor (`@monaco-editor/react`) for browser coding

## Getting Started

1. Set up a `.env` file:
   ```env
   VITE_API_URL=http://localhost:5000
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the Vite server:
   ```bash
   npm run dev
   ```
